About

I break software before someone else profits from breaking it.

Twenty-five years building systems taught me where they fall over, because I was the one who had to keep them up. Building them is still the job, now with agentic engineering as the new half. Security research stays the side gig I'd do for free: application security and vulnerability research. When I'm not building or breaking things, I write about engineering, agents, and the mess in between.

What I Do

Systems engineering

The day job: designing and building production systems in Go, Rust, PHP, and whatever glue holds them together.

Agentic engineering

Agents that do real work: tooling, pipelines, and the harnesses that make them reliable.

Application security

Code review, threat modeling, and hardening for web platforms. WordPress stacks to Go services, judged the way an attacker would judge them.

Vulnerability research

Bugs found before someone with worse intentions finds them. Responsible disclosure, quietly.
