Pylons

Power over your platform, in plain text.

Pylons is two halves. A library of plain-text files that maps your platform: what every package does, what depends on what, which interfaces are safe to build on, which decisions were made and why, and which bugs nearly ate a weekend. And a checker that reads that map and compares it against the actual code, so the documentation cannot quietly rot.

Everything lives under version control beside the code it describes. The ledger is grep-able, diffable and owned by the team, not by a wiki nobody updates.

  • A map of your platform in Markdown with structured front matter, versioned beside the code
  • Records what every package does, what depends on what, and which interfaces are safe to build on
  • Decision records and post-mortems live next to the systems they describe
  • The pylon checker validates the map against the actual code, so the map stays honest
