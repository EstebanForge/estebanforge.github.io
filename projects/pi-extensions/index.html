pi-extensions

A toolbox for the agent that never sleeps.

pi-extensions is the toolbox I maintain for the pi coding agent: twenty-one extensions in one npm workspace, from cross-session memory to agent bridges to review tooling. Each package publishes independently under the @estebanforge scope, so installing one never drags the other twenty along.

The set grows with the workflow: whatever I find myself doing twice becomes an extension, and the workspace keeps them versioned and shipped together.

  • Twenty-one extensions covering memory, bridges, review, and daily-driver workflow
  • Each package installs on its own: pi install npm:@estebanforge/pi-agentmemory
  • Cross-session memory, agent bridges, diff review, and the glue in between
  • Raw TypeScript with TypeBox, no build step
