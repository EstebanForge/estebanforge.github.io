MCP CLI-Ent

Context is precious. Do not be hasty.

Every MCP server you load costs context: tool definitions eat the window before the conversation starts. CLI-Ent flips the model. The servers stay unloaded; when a tool is actually needed, the CLI calls it and hands back only the result.

It reads your existing MCP configuration, speaks HTTP and stdio, and ships as a single static binary for Linux, macOS and Windows. Context guardian, not another daemon.

  • MCP servers stay out of your agent's context window until a tool is actually needed
  • Call tools on demand from the terminal: the agent keeps its budget for thinking
  • Compatible with existing MCP configurations, no new config format
  • HTTP and stdio transports
  • Single static binary, zero dependencies
