Hyperpress

Real-time WordPress UIs, zero React.

Hyperpress is a hypermedia stack for WordPress. It wires Datastar, HTMX and Alpine.js into a coherent layer so interactive pages are built the way WordPress thinks: server-rendered PHP templates answering requests, no SPA build chain, no React runtime.

On top of the hypermedia layer sits a custom field framework with conditional logic, the kind of structure builders usually reach for page-builder plugins to get.

It ships as a WordPress plugin with its home on the plugin directory.

  • Datastar, HTMX and Alpine.js integrated into one coherent stack
  • Rich interactive blocks and pages built with server-rendered PHP templates
  • Custom field framework with conditional logic
  • All the power of real-time UIs, none of the JavaScript/React overhead
