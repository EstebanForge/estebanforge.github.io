The Construct CLI

One command. Clean room. Agents inside.

The Construct is a single-binary CLI that boots a clean, isolated sandbox preloaded with AI coding agents. MicroVMs by default, embedded in the binary itself, with your OCI runtime as the fallback. It keeps the host free of dependency sprawl and keeps your machine safe from prompt-injected or derping agents.

Run any agent with one command from your current directory. No path escape, optional network isolation, zero configuration.

  • One command to run any coding agent inside a secured sandbox spawned from your cwd
  • MicroVMs by default, embedded in the binary: nothing to install
  • Falls back to your OCI runtime when the VM layer is not available
  • No path escape: the sandbox cannot reach outside the directory you launched from
  • Optional network isolation keeps prompt-injected or derping agents on a leash
