lite-serve

PHP dev server for people who hate waiting for containers.

lite-serve is valet-style PHP development without Docker. One command serves every project on your machine as https://.localhost, with MySQL and Mailpit included. I built it because spinning up containers for a personal WordPress site is overkill.

Install is a single curl into ~/.local/bin. From an empty folder to a running site in sixty seconds: mkdir, serve, done.

  • Every project on the machine serves itself at https://<folder>.localhost
  • MySQL and Mailpit included: mail and database without a compose file
  • Local HTTPS that just works in the browser
  • One curl | bash install into ~/.local/bin, one command to update
  • 60 seconds from an empty folder to a running WordPress site
