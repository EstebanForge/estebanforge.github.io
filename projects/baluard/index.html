Baluard

Your passwords, versioned like code.

Baluard is a password manager built on a different storage model: the vault is a git repository. Every change is a commit, sync is push and pull, and conflict resolution is the same merge machinery developers already trust with source code.

The core is pure Rust with no runtime dependencies: modern AEAD encryption, memory-hard key derivation, and an encrypted container format designed so the vault does not leak its own size or structure. On top of it, UI clients for desktop and mobile share one orchestration runtime.

Its real home is baluard.app. This page is the index entry; the site carries the downloads and the docs.

  • Git-native sync: your vault is a repository, history and conflict resolution come free
  • Padded-bucket encrypted storage that hides vault size and structure
  • AES-256-GCM, Argon2id, HPKE, Ed25519 and TOTP under a pure-Rust core
  • Device-identity bootstrapping without a central server
  • Multi-platform UI clients over one shared runtime
