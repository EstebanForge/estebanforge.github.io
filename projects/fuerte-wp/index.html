Fuerte-WP

Updates that can't break your site.

Fuerte-WP is a WordPress security and maintenance plugin built around one idea: updates and access control should work together. Plugin neglect is the most common way WordPress sites break, and most maintenance tools only tell you after the fact.

Fuerte-WP automates the update routine — configurable scheduling, selective updates, live monitoring — and pairs it with administrator oversight, so only the accounts you designate can change what runs on the site. Its blocked-updates mode freezes a plugin at a known-good version and removes the update entirely, which is the tool you want the day a developer account gets compromised and a bad release starts shipping.

It ships as a WordPress plugin with its home on the plugin directory.

  • Auto-update management with configurable scheduling for plugins, themes and core
  • Blocked updates freeze plugins at safe versions during supply-chain incidents
  • Deferred updates keep specific plugins on manual while the rest update on schedule
  • Administrator oversight: super-user control, role-based limits, protected settings
  • Live update dashboard with maintenance logs and exportable reports
  • Self-protecting: cannot be disabled except by a super user or server access
